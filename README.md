# Backlink Intelligence Plugin for Claude Cowork

**Discover, qualify, verify, and campaign. The full link building workflow without leaving Cowork.**

Built by [Artur Ferreira](https://thegeolab.net) | The GEO Lab

---

## Commands

| Command | What It Does |
|---------|-------------|
| `/links:discover [domain]` | Find prospects linking to competitors but not you |
| `/links:gap domain comp1 comp2` | Tier 1/2/3 competitor backlink gap analysis |
| `/links:verify [domain]` | Verify acquired links are live and followed |
| `/links:expired [niche]` | Find expired domains with backlink equity |

## Agent

`link-campaign` — Full autonomous prospecting: gap analysis → discovery → qualification → outreach list with per-prospect context.

## Connectors

DataForSEO · Firecrawl · PostgreSQL · Notion · Google Drive
